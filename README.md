# Minha Lista Tranquila

Aplicação web simples e gentil para ajudar pessoas a externalizar pensamentos,
reduzir sobrecarga mental e visualizar progresso de forma calma e humana.

## Objetivo
Transformar a “lista mental invisível” em algo concreto, leve e organizado,
sem pressão, sem métricas agressivas, sem ansiedade.

## Princípios
- Linguagem em pt-BR
- UX calmo e acolhedor
- Mobile-first
- Sem frameworks no início
- Evolução contínua

## Estado do projeto
Fase 1 — Estrutura inicial e telas estáticas
