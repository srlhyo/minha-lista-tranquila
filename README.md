# Minha Lista Tranquila

Um espaço calmo para externalizar pensamentos e reduzir a sobrecarga mental. 
Este não é um app de produtividade, mas sim uma ferramenta de clareza mental.

## Fase 1A: Login & Design System Base

Esta fase foca na fundação visual e na tela de entrada do aplicativo.

### Como rodar localmente

Este projeto utiliza apenas HTML, CSS e JavaScript puros. Não há necessidade de `npm install` ou build steps complexos.

1. Clone o repositório.
2. Navegue até a pasta do projeto.
3. Abra o arquivo `src/index.html` no seu navegador.
   - Ou use uma extensão como Live Server (VS Code) apontando para a pasta raiz.
   - Ou, se tiver python instalado: `python3 -m http.server` e acesse `localhost:8000/src/`.

### Estrutura de arquivos

- `src/index.html`: Tela de Login.
- `src/css/styles.css`: Variáveis globais, reset e estilos.
- `src/js/app.js`: Lógica simples de navegação.
- `src/pages/lista.html`: Placeholder para a próxima fase.

### Stack

- HTML5
- CSS3 (Variáveis, Flexbox/Grid)
- JavaScript (ES6+)
- Sem dependências externas
